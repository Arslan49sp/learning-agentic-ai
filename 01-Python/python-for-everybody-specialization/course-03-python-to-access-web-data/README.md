# 🌐 Using Python to Access Web Data
### (Python for Everybody – Course 3)

This module focuses on **fetching, parsing, and processing data from the web using Python**.

Instead of working only with local files, we learn how to:
- talk to servers
- read web pages
- call APIs
- process structured data (JSON / XML)

This is my first step toward **real-world automation, backend scripting, and eventually Agentic AI systems**.

---

## 🎯 Goals of This Module

By the end of this course, I can:

✅ Send HTTP requests using Python  
✅ Download web pages and files  
✅ Parse HTML using BeautifulSoup  
✅ Extract data using Regex  
✅ Work with APIs  
✅ Read JSON and XML data  
✅ Automate web data collection
